## Definition
Shell Scripting is a sequence of of shell commands stored in a file usually with `.sh` extension, in addition to that, it has the advantage of using programming logic like conditional statements (if, else,...etc), and variables ($).

## What for
Shell scripts are used to improve productivity, by shortening repetitive tasks.
## How to
It starts by creating a file, usually has a .sh extension:
```bash
vim script.sh
```

```script.sh
#!/bin/bash
#Log the date and time the script was last executed
date >> /tmp/script.log
cat /proc/version >> /tmp/script.log
```
- the .sh extension is optional, but it is standard practice to distinguish between other files and shell scripts, but you need to remove them to allow other programs to execute them.
- #!/bin/bash called the shebang @WikipediaShebangUnix2024, it specifies the full path to the command interpreter that will run the script, in this case bash, others like fish, zsh,...etc.
- (#) sign means what follows is a comment, will be ignored, and it is used to explain stuff, and for future reference.
- `date`: command to show the current date.
- /proc/version is a file that contain information about the current system.
## Builtin Commands
A builtin command is a command that the shell carries out itself, to list the builtin commands type help in the command prompt. @peter.oWhatDifferenceBuiltin2011; @ShellBuiltinCommands2023

### If statement 
if is a builtin command, it is similar to the if statement in programming languages, 

```bash
if test -f /tmp/archive.tar.gz; then
	mv /tmp/archive.tar.gz /tmp/archive.tar.gz.OLD
	tar acf /tmp/archive.tar.gz /etc/apt/
else
	tar acf /tmp/archive.tar.gz /etc/apt/
	fi
```
