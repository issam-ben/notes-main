## Using systemctl to Reboot and Shutdown a Linux Machine
-  Reboot a Linux System
```bash
sudo systemctl reboot
```
-  Shutdown a Linux System
```bash
sudo systemctl poweroff
```

### Forcing shutting down and rebooting a linux system

```bash
sudo systemctl reboot --force
```

```bash
sudo systemctl poweroff --force
```
#### Double forcing
```bash
sudo systemctl reboot --force --force
```

```bash
systemctl poweroff --force --force
```


> [!NOTE] Last resort
> Use the double force option only as a last resort, it is like unplugging the outlet from the computer or pressing the power button.

## Schedule a Reboot or Shutdown of a Linux System
Sometimes you will have to schedule a reboot or shutdown of your workstation or servers, maybe because it is the middle of the night and you are already asleep, or away.

### Schedule a reboot
- Reboot at a specific time
```bash
sudo shutdown -r 02:00
```
- Reboot after specified minutes
```bash
sudo shutdown -r +15
```
### Schedule a shutdown
- Shutdown at a specific time
```bash
sudo shutdown 02:00
```
- Shutdown after specified minutes
```bash
sudo shutdown +15
```

> [!NOTE] Time format
> The time format for scheduled reboot and shutdown is 24h, you can use any time between 00:00 to 23:59. 

### Setting a wall message
Wall message: is a message that gets displayed in the terminal on every logged in user.
```bash
sudo shutdown -r +1 'Scheduled restart to do an offline-backup of our database'
```
