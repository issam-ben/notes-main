## What is a process
In general, a process is an executed program.
### Process types in Linux
#### Based on their work:
- Foreground Processes (interactive processes): which are dependent on user input, like normal programs (web browser, email client...).
- Background Processes (automatic processes): run independently from the user. like services (webserver, ssh daemon, printer,...) @CommandsProcessManagement
#### Based on their life
- Short lived: ls, pwd, ps
- Long Lived:ssh, httpd,

- ps, is the cli tool used to manage processes.
- ps supports 2 kinds of syntax:
    - Unix:ps -a
    - BSD: ps a
    - have different affects
    - ps by default will show us only processes that are launched from the same session or terminal window.
    - to make ps show all processes use:
        - ps aux
        - -a= all proc exept...
        - -u=user oriented format
        - -x= lift bsd format
        - -A,-e= all processes
        - ps output:
            - %CPU: percentage of cpu the process is using of one single core, 100% means the full core, 1.5 means full core, and half of another core.
            - %MEM: shows how much percentage of total memory the process is using.
            - START: shows the time the process was started or the date if the process wasn't started today.
            - TIME: how much cpu time is used during the process's lifetime. to get 1 sec of cpu time, the process will get 100% of a cpu core for an entire second, and if it gets 50% of 10 sec, it will get around 5 sec of cpu time.
            - COMMAND: shows the command used including options to start this process, processes between [] are kernel processes.
- top, another cli tool to manage processes.
