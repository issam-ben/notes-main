## What is a Firewall
Firewall is a computer security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules@FirewallComputing2024. it separates a trusted network from an external network deemed untrustworthy, like the internet.@WhatFirewall 
## Types of Firewalls
### Packet Filtering Firewall
This type of firewalls carefully examine each packet of data, and filters them based on parameters like source and destination, port numbers, and protocol types.
- Pros: 
	- Simple and Cost effective.
- Cons: 
	- Unable to Examine packets content which makes them less effective against sophisticated attacks.
### Proxy Firewall
An Early type of firewall, that acts as the gateway between a network and a larger network, for a specific application.
- Pros:
	- Enhanced Security.
	- Privacy
	- Advanced threat detection
- Cons:
	- Degrade network performance
	- Protocol limitations
	- Complexity
