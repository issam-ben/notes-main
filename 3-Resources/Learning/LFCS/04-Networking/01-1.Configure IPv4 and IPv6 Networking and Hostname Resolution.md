# IP Address
Internet Protocol

## IPv4
IP addresses v4 looks like this:
`192.168.1.1`
Four 8bit numbers that are separated by a dot, each can take the value between 0-255, which is what can be represented in 8bits. for example:
```
00000000 in binary is 0 in decimal.
00000001 is 1
00000010 is 2
....
11111111 is 255 
```

### CIDR Notation
Stands for **Classless Inter-Domain Routing**, which is a method for allocating IP Addresses for IP Routing.@ClasslessInterDomainRouting2024
It format looks like this:
`192.168.1.1/24`
`/24`: is called Network Prefix which is the [most significant bit](https://en.wikipedia.org/wiki/Bit_numbering#Most_significant_bit), or the left section, and the number 24 means 24 bits, so in this case the first three sections of the IP address is the fixed section, and the last four is the one available to assign.
## IPv6
It is similar to IPv4, bit it has a whole 128bits Address, with 8 groups instead of 4, and represented in Hexadecimal unlike IPv4, its format looks like this:
```
2001:0db8:0000:0000:0000:ff00:0042:8329
```
And shortened like this:
```
2001:db8::ff00:42:8329
```
By removing lead 0s.
it also supports the CIDR notation, like:
```
2001:0db8:0000:0000:0000:ff00:0042:8329/64
```
First 64bits represent the Network Prefix, Each group of 2 hexadecimal digits is 8bits in binary, so in this case the network prefix is the first four sections of the IP address.

**==2001:0db8:0000:0000:0000==:ff00:0042:8329**

Calculating network prefix can be tedious some times, for ex in the case of 192.168.1.1/10, the CIDR notation is to take the first 10 bits after converting to binary:
```
192.168.1.1 # IP Address in Decimal
11000000.10101000.00000001.00000001 # In Binary
11000000.10 # First 10 bits
11111111.11000000.00000000.00000000 # make 1st 10 bits to 1.
255.192.0.0 # Convert to decimal subnet mask.
```
