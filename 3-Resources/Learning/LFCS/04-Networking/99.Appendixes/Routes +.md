## Routing
Routing is the process of getting packets from a source to a destination in a network. it uses Routers for this.
Routers like any other device in a network, has an IP address, that address can be used by other devices to reach other devices. 
using routing tables on linux, we can specify which gateways the system uses to reach a specific client on a network, be it the same network or another one.
