
# View text files:
## cat Command
To view content of text files.
* Syntax:
```
cat /path/file.txt
```

### tac Command
to view text files in reverse order

## tail command 
To view the last lines of a text file
* Syntax:
```
tail /var/log/dnf.log
```

to view specific number of lines:
```
tail -n 20 /var/log/dnf.log
```

## head command
To view the first lines of a text file:
* Syntax:
```
head /var/log/dnf.log
```

# Transform text

## sed Command

sed (Setream EDitor), A stream editor is used to perform basic text transformations on  an  input  stream  (a file or input from a pipeline).

* Syntax:
```
sed SCRIPT INPUTFILE...
```

### replace occurrences of a word in text file

```
sed 's/hello/world/g' input.txt 
```

' ': to tell our shell interpreter not to interpret the quote as a command.
s: subtitute command, search and replace.
/hello: the word to find.
/world: the word to replace the original with.
g: to tell sed to search and replace in the whole text, normally sed only deals with the first occurrence. 


> [!-i] in place
> "-i" option means in place, it tells sed to write the changes to the original file, the command above will not write changes, it just will show changes, to make sure for ex.

```
sed -i 's/hello/world/g' input.txt 
```

# View certain parts of a text file

## cut Command
* Syntax:
```
cut option file
```
* Examples:
	-  to cut the first column
```
cut -d '' -f 1 textfile.txt
```
 -d: indicates the use of delimiter; which is one or more characters that separate text strings. [1](https://www.computerhope.com/jargon/d/delimite.htm)
 ' ': specify that the a single space is the separator of words in our file.
 -f 1: the field, specify the field that we want to cut, which is in our example every first word of each line.
## uniq command
view only unique words in a text file. it removes repeating lines that are adjacent.

- Syntax: 
```
uniq [OPTION]... [INPUT [OUTPUT]]
```

* Examples:
	* Show unique country names in a file
```
uniq countries.txt

usa
canada
usa
canada
```
the output shows repeated results, because uniq remove only adjacent lines.

to solve this we first need to sort the names using *sort* command, and pipe the output through the unique command,
```
sort countries.txt | uniq

canada
usa
```

# Comparing Files
## diff Command
- Syntax
```
diff option file1 file2
```
-c context: output NUM (default 3) lines of copied context
-q, --brief: report only when files differ.
-y side by side: output in two columns.

### sdif
Like the diff command, sdiff shows us the comparison side by side.
