# Intro
Imagine we have to look inside configuration files scattered throughout the filesystem for IP Addresses inside them. IP Addresses has a pattern of four slots separated each by a dot, like (192.168.122.150), we can't look for numbers with a dot between them, because this will show results like '1.2' which is not an IP address.
this will need more advanced search instructions.
In math we can say:
x is an integer
x > 3
x > 8
This means the result is either 4, 5, 6, or 7, regular expressions work in a similar fashion.
# Regex Operators
## (^ Caret) Line begins with
It matches the start of a string.
- Syntax
```
grep '^xxxx' file
```

## ($ Dollar sign) Line ends with
It matches the end of a string.
- Syntax
```
grep 'xxxx$' file
```
## (. Dot-Period) Match any one character
It represents missing characters, if you look for the word apple, and you forgot one or two letters of the word, put dot instead.
It matches even words that contain the word apple like cossinapple.
To avoid it finding whole words that contain characters, use grep's -w option.
- Syntax
```
grep 'ap..e' file
Output:
apple
cossinapple
---
grep -wr 'ap..e' file
Output:
apple
```

## ( "\" Backslash) Escape character
It will ignore special symbols like whitespace " ", "\n" newline and dot " . ".
e.g: to find IPs that start with 192.168. :
```
grep '192.\168.\'
```

## * (asterisk)Match previous elements 0 or more times
It matches previous character 0 or more time, meaning, if we take the expression 'let*', this will look for any match that contain two or more of these letters, in condition it should match the start of the string.
```
let* expression will find some of these results if found:
let
llleeettt
leeettt
lettt
```

## + (Plus Sign) match previous one or more times
Like the asterisk, the plus sign matches the occurrence of characters one or more times, if we take the expresssion 'led+'. if we take the expression 'led+' in LFCS-Fedora-VM/home/issam/lfcs-exercises/01/plus-sign.txt:
```
grep -i 'led\+' plus-sign.txt
```

> [!NOTE] Basic RegEx
> Notethat we escaped the plus(+) sign, that's because grep uses basic regular expressions 'BRE', which requires to escape all these signs ==+,{},?,|[], ()==. to mitigate this use 'E' option with grep (grep -E) or the command egrep (Extended GREP).
## {} (Bracket), match previous {n, m} times
It matches the previous item more than n times, and less than m times. if we want to search for the number 0 matched 3 to 10 times:
```
egrep -r '0{3,10}' textfile
```
## ? (Question mark) previous element optional
It indicates that the preceding element is optional and can appear zero or one time. let's take for example the expression 'colou?r', it will find colour and color.

## | (Pipe/Or), match one or another pattern
It acts like or operator, it means that match one of many patterns. for example if we want to search for the word cat, or the word dog, it will show both of them if both are found, or just one if one only is found.
## [] (Square Brackets) Ranges or sets
It can either:
- Match a range of characters like [a-z] which will match letters between a,b,c...z,
- set of characters inside the square brackets like [a,b,c], which will match either a, b, or c, or [10-1000] which will match every number from 10 to 1000.
### Negation

You can negate a character class to match any character not listed within the brackets:

1. **Negation**:
    - **Pattern**: `[^abc]`
    - **Matches**: Any character except "a", "b", or "c"
    - **Explanation**: The `^` at the beginning of the brackets negates the character class.
2. **Negating a Range**:
    - **Pattern**: `[^a-z]`
    - **Matches**: Any character that is not a lowercase letter
    - **Explanation**: The `^` at the beginning negates the entire range of lowercase letters.
## () Parentheses - Subexpressions 
It is used for grouping or capturing:
### Grouping
Grouping parts of a regular expression which can be useful for applying quantifiers to multiple characters or patterns.
1. **Basic Grouping**:
    
    - **Pattern**: `(abc)+`
    - **Matches**: "abc", "abcabc", "abcabcabc", etc.
    - **Explanation**: The pattern `abc` is grouped and the `+` quantifier applies to the entire group, matching one or more occurrences of "abc".
2. **Alternation with Grouping**:
    
    - **Pattern**: `(cat|dog)`
    - **Matches**: "cat" or "dog"
    - **Explanation**: The `|` operator applies to the entire group, matching either "cat" or "dog".
### Capturing
Capture groups can be used to extract parts of the matched string.
