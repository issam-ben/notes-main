# How to get help about a command
## --help option, 
 cat for example:
```
$ cat --help`
`Usage: cat [OPTION]... [FILE]...`  
`Concatenate FILE(s) to standard output.`  
  
`With no FILE, or when FILE is -, read standard input.`  
  
 `-A, --show-all           equivalent to -vET`  
 `-b, --number-nonblank    number nonempty output lines, overrides -n`  
 `-e                       equivalent to -vE`  
 `-E, --show-ends          display $ at end of each line`  
 `-n, --number             number all output lines`  
 `-s, --squeeze-blank      suppress repeated empty output lines`  
 `-t                       equivalent to -vT`  
 `-T, --show-tabs          display TAB characters as ^I`  
 `-u                       (ignored)`  
 `-v, --show-nonprinting   use ^ and M- notation, except for LFD and TAB`  
     `--help        display this help and exit`  
     `--version     output version information and exit`  
  
`Examples:`  
 `cat f - g  Output f's contents, then standard input, then g's contents.`  
 `cat        Copy standard input to standard output.` `

## man Command
Manual pages for commans.
* syntax:
```

# man Command

* ex:
```
man journalctl
```

### man Sections
sometime you'd have some commands that has the same name as functions (library calls)...etc, to see these sections use man command on man:
```
man man
```

and the sections are as follows:
```
	  1   Executable programs or shell commands  
      2   System calls (functions provided by the kernel)  
      3   Library calls (functions within program libraries)  
      4   Special files (usually found in /dev)  
      5   File formats and conventions, e.g. /etc/passwd  
      6   Games  
      7   Miscellaneous (including macro packages and conventions), e.g. man(7), groff(7), man-pages(7)      
      8   System administration commands (usually only for root)  
      9   Kernel routines [Non standard]

```

> [!Hint] commands section
> commands are only in 1 and 8 section

For example there is a printf command and function, to specify what you want to see use the section numbers like:
- to see the command section
```
man 1 printf
```
- to see the function section:
```
man 3 printf
```

# aprpos Command
To search the manual pages names and descriptions, we use it to find commands if we forget them, for example if we forget the command to create a directory we can search for it by using the whole word or parts of it, like:
```
apropos director
```

to specify which section we need to look for we use ==-s== option like:
```
apropos -s 1,8 director
```
