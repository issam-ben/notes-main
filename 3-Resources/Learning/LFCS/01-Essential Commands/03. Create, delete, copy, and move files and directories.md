# List files and directories

## ls Command
- Syntax:
```
ls -option location
```
- Ex: 
```
ls -la /
```
- l option: long listing format.
- a option: All files including hidden files.
# Linux file-system tree

The linux File-system has a tree like hierarchy, Called Filesystem Hierarchy Standard [FHS](https://www.pathname.com/fhs/)  The main starting point is the root directory (/), and branches down to other directories.
## Filesystem function:
- the main function of a filesystem is to provide space for non-volatile storage of data.
- It also provide namespace which is, a naming and organizational methodology, such how files can be named, like what type of characters are allowed, and its length.
- It also defines the logical structure of data on disk: like the use of directories for organizing files instead of stacking them all together in a single place.

### Absolute paths
Absolut paths is the location of a file a directory from the root directory, like
```
 /home/user/.ssh/known_hosts
```
it includes every directory starting from the top level to the wanted location, while;

### Relative paths
Relative path is the location of a file or directory relative to the current location, like:
if we are inside the path /etc/ the relative path to the file ssh_config is /ssh/ssh_config, notice that the previous directories from / to /etc are omitted, this makes the path accessible only from inside the /etc directory.

# Listing files and directories
to list the files and directories inside a directory we us the the 'ls'(list directory contents) command.
```
fedora-srv-vm:~$ ls  
cat.txt  countries.txt  diff1  diff2  userinfo.txt
```

* Specify absolute path
```
@fedora-srv-vm:~$ ls /etc/ssh/  
moduli        sshd_config         ssh_host_ecdsa_key.pub    ssh_host_rsa_key  
ssh_config    sshd_config.d       ssh_host_ed25519_key      ssh_host_rsa_key.pub 
ssh_config.d  ssh_host_ecdsa_key  ssh_host_ed25519_key.pub
```

- List all files and directories (inc hidden ones)
we use the -a option
- Long listing format: we use the -l option to show the listing with more info like owners, permissions, size...etc
- list file/dir sizes in human readable format: we use the -h option.

# Current working directory
is the directory where all the commands are being executed. to know the current working directory we use the command 'pwd' (print working directory)
```
fedora-srv-vm:~$ pwd  
/home/user
```

# Change current directory
to change the current directory and move to another directory we use the command 'cd', which stands for change directory 
```
fedora-srv-vm:~$ cd /usr/lib/  
fedora-srv-vm:/usr/lib$ pwd  
/usr/lib
```
- Change to the parent directory: we use the .. after the cd command:
```
cd ..
```
- change to the previous directory: we use '-' as a directory
```
cd -
```
- change to user home direcotory: we use the '~' as a directory
```
cd ~
```

# Creating files
to create file we use the command 'touch'
```
touch note.txt # this will a note.txt file inside the cwd.
```

# Creating directories
to create new directories (folder), we use the 'mkdir' (MaKe DIRectories)
```
mkdir notes
```

# Copying files
to copy files we use the 'cp' (copy) command 
```
cp source destination

cp note.txt notes/ #it is recommended to use slash with dirs

cp note.txt notes/note_copy.txt # to copy the file in a new name.

```

# Copying directories
to copy directories and all their contents use use the 'cp' command with '-r'(recursive) option.
```
cp -r notes/ backupnotes/ 
```

# Moving files
we use the 'mv' (move) command.
```
mv notes/note_copy.txt backupnotes/
```

# Deleting files and Directories
we use the 'rm' (remove) command 
```
rm note.txt # to delete a file
rm -r notes/ # -r option to delete dir and content
```

# Other Notes
* copying directories:
if you do it like this cp /path/to/directory/* it will copy all files but not the directory.
- to preserve files permissions when copying to another directory, use the ==*-p== option.
