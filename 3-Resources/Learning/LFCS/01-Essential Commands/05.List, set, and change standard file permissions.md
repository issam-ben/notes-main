# Owners and Groups
Owner is the owner of the file or directory, groups are group that the user belongs to.

- Change Group command
==chgrp group_name file/directory==

- Change owner User command:
```
chown user_name file/directory
```
- Change Owner and Group:
```
chown user:group file/directory
```
# Permissions 
## Types of ls Listing
ls command lists files and directories inside a directory, it also shows their permissions and their types, (before the permissions) file or directory or else, the table below shows what every entry means:

| type             | identifier |
| ---------------- | ---------- |
| Directory        | d          |
| Regular file     | -          |
| Character Device | c          |
| Link             | l          |
| Socket file      | s          |
| Pipe             | P          |
| Block Device     | b          |
## Permission codes
when ==ls== lists us files and directories it lists their permissions in as 9 characters ==rwxrwxrwx==: 
- 1st 3 characters belong to the owner.
- 2nd 3 characters belong to the Group.
- 3rd 3 characters belong to others, that is anyone that is not the user, and not in the group.
r=read: means the user can read the files, access the directory.
w=write: means can modify the content.
x=execute: means can execute binary files.
-= no permission.
## Evaluating Permissions
The command line evaluate permissions from left to right, so if user1 is the owner of a file, his/her permissions will apply, if not the owner and is part of the group, the group permissions will apply, if not the owner and not in the group, the other permissions will apply.
## Change Permissions
To change permissions of a file or directory we use the ==chmod== command.
- syntax: 
```
chmod x+rwx file/dir # to give read, write, execute permmissions
x= u+(user), g+(group), o+(others)
```
## Remove permissions
we use x-(x=(u=user,g=group,o=others)), instead of x+.
```
chmod u-w file # to remove write permission from the owner
```
## Set exact permissions
use = instead of +, if you want to remove all permissions, don't specify anything after = sign.
## Chain Permissions
to chain permission we can separate them with a coma like:
```
chmod u=rwx, g=rwx, o-r file
```
## Octal Permissions
Permissions in Linux can be represented in binary, where 0 is no permission, and 1 a certain permission like in this table, the permission number contains 4 digits, 0777 for e.g: 

| octal   | 0                                          | 7    | 7     | 7      |
| ------- | ------------------------------------------ | ---- | ----- | ------ |
| meaning | special permission, SUID, SGID, sticky bit | user | group | others |


| Code   | rwx | r-- | --- |
| ------ | --- | --- | --- |
| Binary | 111 | 100 | 000 |
| Octal  | 7   | 4   | 0   |
we need to convert those binary values to Octal system as shown in the table, to be able to set permissions with numbers.
setting the permission with chmod in octal like this:
```
chmod 740 filename
```
will make the file rwx to owner, read only to group, and no permission to others.
