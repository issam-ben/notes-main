# Archiving (Packing), Compressing and Backup

Scenario: To backup files, in the linux world, it is casual to archive the files, the complete process would take 3 steps:
- 1- Archiving: the first step is to put all those files into a single file called archive,  usually using "tar".
- 2- Compressing: the second step is compressing the archive, make it smaller in size, to save up space, using "gz" for example.
- 3- Backing up: which is saving the backup file to the designated space where it should be safe, and accessible to retrieve backups when needed, like a disk, remote server, cloud storage...etc.
# Archiving (Packing)
tar/tarball= tape archive, it is know back in the day when backups where saved on magnetic tapes, tar was the tool for it in Unix systems. since then tar is still used for this role to this day because it does it well.
Packing simply is taking numerous files and gather them in one single file, in this case ".tar" file. Tar also is an unpacker, we can use it to upack the archive to normal files.
## Packing files and directories with tar

### Packing Archives
To pack a file or many files using the "*tar*" command use the following options:
```
tar --create --file archive.tar file1 file2 file3 file4
tar cf archive.tar file1 file2 file3 file4
```
### Listing Archive Files
To list a tar archive file, using the command "*tar*", use the following options:
```
tar --list --files archive.tar # long option
tar -tf archive.tar # short option
```

### Add File to an Archive
Use these options:
```
tar --append --file archive.tar file5
tar rf archive.tar file5
```

### Pack/Add Directories and Content to an Archive
Use these options:
```
tar --create --file Photos/
tar --append --file Photos/
Photos/  
Photos/t.jpg  
Photos/a.jpg
```
#### Absolute Paths
When using absolute paths to pack an archive, the archive paths will take the absolute paths, meaning they will appear as the path of the original files, like this:
```
$ tar -tf archive2.tar    
home/user/Pictures/Photos/  
home/user/Pictures/Photos/cat.jpg  
home/user/Pictures/Photos/dog.jpg  
home/user/Pictures/Photos/lion.jpg
```

### Extract Archive
Use these option:
```
tar --extract --file archive.tar
tar -xf archive.tar
```

> [!NOTE] Where ?
> tar Extracts content on the current directory by default

#### Extract to another directory
Use these option:
```
tar --extract --file archive.tar --directory /tmp/
tar xf archive.tar -C /tmp/
```

> [!NOTE] Content Permission
>  tar Keeps content permissions, so if a file inside the tar archive is created by another use, the current user don't have the permissions to create a file created by another use, but the root user does have.


# Compressing and Decompressing
Most linux distros have three default compression/decompression tools installed, gzip, bzip2, and xz

## Compressing Files
### gzip
```
gzip file
```
### bzip2
```
bzip2 file
```
### xz
```
xz file
```
## Decompressing Files
### gzip
```
gunzip file.gz
gzip --decompress file.gz
```
### bzip2
```
bunzip file.bz2
bzip2 --decompress file.bz2
```
### xz
```
unxz file.xz
xz --decompress file.xz
```

> [!NOTE]
> All previous commands will have the original file deleted. Meaning that when compressing and decompressing, the file that the action was done to gets deleted

## Keeping Original Files
To make the tool "gzip, bzip2, and xz" keep the original file, use the following options:
```
gzip -k or --keep
bzip2 -k or --keep
xz -k or --keep
```

### Using Tar with gzip, bzip2, xz

Due to that these tools don't have archiving capabilities, to compress multiple files, it is a best practice to use tar with them:
Either by:
- Archiving the files with tar first, and then compress them.
- using a single tar command :
```
tar czf archive.tar.gz file1 file2 ...
tar --create --gzip --file archive.tar.gz file1 file2 ...
---------
tar cjf archive.tar.gz file1 file2 ...
tar --create --bzip2 --file archive.tar.gz file1 file2 ...
---------
tar cJf archive.tar.gz file1 file2 ...
tar --create --xz --file archive.tar.gz file1 file2 ...
```

### Autocompress with tar
To make tar automatically compress files use the following options:
`--autocompress`
`-a` o|r `caf` 
- Examples:
```
tar caf archive.gz file1 file2 ... # for gzip
tar caf archive.bz2 file1 file2 ... # for bzip2
tar caf archive.xz file1 file2 ... # for xz
```

> [!NOTE] How ?
> tar Automatically detects the compression tool based on the file extension. so using `a` `--autocompress` option is useful
