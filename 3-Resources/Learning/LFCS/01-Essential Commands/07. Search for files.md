# Find Command

Syntax: 
***find ([path/to/directory]) ([search_parameters])***
e.g: 
find /bin/ -name file1.txt
find -name file1.txt
*==**no path means current directory.**==*

## Search Parameters 

- name: searches for files by name, and it is a case sensitive.
```
  $ find /usr/bin -name ls
```
	- using a wildcard (*) can be used to search for files starting with a letter, like "find /usr/bin -name "f*" to seatch for all files starting with f.
- iname: case insensitive search for file by name.

- mmin: modified minute, searches for files by modification time
	- find files modified in the last 5 minutes: +5 for greater than 5min, -5 for less than 5min.
```
$ find /etc/ -mmin 5
```
- mtime: search for modified files by day or hours, 0 means last 24 hours:
```
  find /etc/ -mtime 0
```

- cmin: search for files that has been changed in past time
```
  find /etc/ -cmin -5
```

There are 3 kind of "timestamps":
- Access - the last time the file was read
- Modify - the last time the file was modified (content has been modified)
- Change - the last time meta data of the file was changed (e.g. permissions)] [1](https://unix.stackexchange.com/questions/2464/timestamp-modification-time-and-created-time-of-a-file)

- size: search for files by their size:
```
  find /usr/bin -size 512k #search for file of 512 kilobytes size
```

> +/- like previous parameter, + means greater than, - less than.

| Symbol | Value     |
| ------ | --------- |
| c      | bytes     |
| k      | kilobytes |
| m      | megabytes |
| g      | gigabytes |
|        |           |
- -perm: search for files by their permissions 
```
find /usr/bin -perm 555
find /usr/bin -perm -555 # at least 555 perm
find /usr/bin -perm /555 # with any of these perm
find /usr/bin -perm u=rw,g=rw,o=r 
find /usr/bin -perm -u=rw,g=rw,o=r
find /usr/bin -perm /u=rw,g=rw,o=r
```
### Multiple options 
Parameters can be combined together to expand the search criteria, like if we want to find a file that starts with the letter "g" and its size is 14k:
```
find /usr/bin -name "g*" -size 14k
```

- Or operator: add "-o" flag
```
find /usr/bin -name "g*" -o -size 14k
```
- Not operator: "-not", "\!"
```
find /usr/bin -not -name "g*" # search for file that don't start with g.
```
