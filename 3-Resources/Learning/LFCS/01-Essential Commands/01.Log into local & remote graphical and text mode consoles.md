# Log in
is the process by which an individual gains access to a computer system, by identification and [[Authentication]]. 
# Local & Remote
## local: 
means the computer you use in front of you.
## Remote:
means a computer that is not in front of you, located in a data center or office, or another house, or even a virtual machine.
# GUI & CLI
GUI: Graphical User Interface, is a computer software interface that uses graphical shapes to control the computer, like buttons, cursor, windows,...etc.
in the past, Computers were huge, and many users use it at once, by using a piece of equipment called Terminal or console, that allows the user to interact with the mainframe computer, in the early days of Unix it meant a Teleprinter device like a typewriter sometimes called teletypewriter (tty for short).
CLI: Command Line Interface, is an interface that uses only text, to control the computer, by typing commands.
- Terminal: a Unix I/O handling device, a kind of [device file](https://en.wikipedia.org/wiki/Device_file), which implements a number of additional commands ([IOCTLS](https://en.wikipedia.org/wiki/Ioctl#Terminals)) it usually means a pseudo-terminal (pts) or pseudo-ttys or [terminal emulators](http://en.wikipedia.org/wiki/Terminal_emulator), that allows access and use of the shell eg: a terminal emulator like 
	- Kde Konsole, Gnome Terminal; Xterm.
	- Tmux
	- SSH.
- Console: a Terminal in the Physical sense.
The name terminal comes from an Electronic point of view, and Console from a furniture point of view.

- Shell: a command line interpreter, invoked when a user logs in, it acts like a layer between the user and the kernel, its primary purpose is to start other programs.
