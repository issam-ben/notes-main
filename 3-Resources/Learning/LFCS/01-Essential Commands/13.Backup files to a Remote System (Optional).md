# Syncing 2 Directories 
## (rsync) Remote Synchronization
A tool that is available by default in most Linux Distros, it keeps a local directory synchronized with another directory in another station or server, by copying data on a network connection, it uses SSH, it synchronizes only modified content.
- Syntax
```
rsync -a /path/to/local/dir/ user@remote_ip:/path/to/remote/dir
--------
rsync - /home/user/backup/ user@192.168.122.100/home/backup/
```

`a` `--archive`: Archive option, it makes sure that rsync, synchronizes subdirectories, file permissions, modification time, and so on.

### sync Remote dir As source
In the previous example, rsynce will make the local directory the source, and the remote dir, the destination.
```
rsync -a user@192.168.122.100/home/backup /home/user/backup/
```
### Syncing two or more Directories
- Syntax:
```
rsync -a /dir1/ /dir2/ user@remote_ip:/path/to/remote/dir
------
rsync -a /home/user/backup/ /mnt/Partition_1/backup user@192.168.122.100/home/backup/
```
## (dd) Disk Imaging
It deals with disks, and Partitions:
- it copies exact bit by bit of the data on disk or partition (Imaging).
- Disk or Partition should be unmounted before imaging, to make sure that data inside is not being changed.
	- Syntax:
```
sudo dd if=/dev/vda of=diskimage.raw bs=1M status=progress
```
`sudo`: You have to have the root permissions.
`if=/dev/vda`: read from file instead of stdin, it specifies the disk or part that we want to backup`/dev/vda`.
`of=diskimage.raw`= write to file instead of stdout, it specifies the file that we want to put the backed up data to `diskimage.raw`.
`bs=1M`: Block Size, read and write up to BYTES bytes at a time (default: 512); overrides ibs and obs. it specifies the size of data written at a time.
`status=progress`: it shows the progress of the operation.

### Restore disk Image from dd file
If we want to restore of Disk, or Partition backup, from a file to the disk or part, we have to reverse the `if=` and `of=` options:
- Syntax:
```
sudo dd if=diskimage.raw of=/dev/vda bs=1M status=progress
```
By doing this we reversed:
- `of=` write to file with instead of stdout, with,
- if= read from file instead of stdin.

> [!warning] Don't do this on VM
> Because it will overwrite the virtual disk. 
> Seek further info about the case
