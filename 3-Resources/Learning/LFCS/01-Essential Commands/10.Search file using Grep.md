# grep
Is a command line utility that searches for, manipulates and prints lines that match a pattern.
* Syntax:
```
grep [OPTION...] PATTERNS [FILE...]  
grep [OPTION...] -e PATTERNS ... [FILE...]  
grep [OPTION...] -f PATTERN_FILE ... [FILE...]
```
E.G:
```
grep '2024-05-18' /var/log/dnf.log 
# to search in dnf log for logs that match the date '2024-05-18'
```
## Options
### Case Insensitive search (-i)
To search for text without worrying if it is upper case or lower case, use '-i' option.
```
user@fedora-srv-vm:~$ grep -i 'fedora' /etc/os-release    
NAME="Fedora Linux"  
ID=fedora  
PRETTY_NAME="Fedora Linux 40 (Server Edition)"  
LOGO=fedora-logo-icon  
CPE_NAME="cpe:/o:fedoraproject:fedora:40"  
HOME_URL="https://fedoraproject.org/"  
DOCUMENTATION_URL="https://docs.fedoraproject.org/en-US/fedora/f40/system-administrators-guide/"  
SUPPORT_URL="https://ask.fedoraproject.org/"  
REDHAT_BUGZILLA_PRODUCT="Fedora"  
REDHAT_SUPPORT_PRODUCT="Fedora"
```

### Invert match "Exclude keyword" (-v)
To exclude results that doesn't include a search word, we use the '-v' option (invert match).

```
sudo grep -iv 'fedora' /etc/os-release    
VERSION="40 (Server Edition)"  
VERSION_ID=40  
VERSION_CODENAME=""  
PLATFORM_ID="platform:f40"  
ANSI_COLOR="0;38;2;60;110;180"  
BUG_REPORT_URL="https://bugzilla.redhat.com/"  
REDHAT_BUGZILLA_PRODUCT_VERSION=40  
REDHAT_SUPPORT_PRODUCT_VERSION=40  
SUPPORT_END=2025-05-13  
VARIANT="Server Edition"  
VARIANT_ID=server
```

### Lines that form whole words (-w)
To search for results that exactly matches the search word, for example, if we search for the word 'red', results like 'redhat' will appear, with '-w' option it will only show the results that form a whole word like 'red'.

```
@fedora-srv-vm:~$ grep -iw 'red' /etc/containers/registries.conf.d/000-shortnames.conf  
 # Red Hat Enterprise Linux
```

### Only Matching (-o)
Prints only the matched (non-empy) parts of a matching line, with each part on a separate line.

```
grep -io 'red' /etc/containers/registries.conf.d/000-shortnames.conf  
Red  
red  
red  
red  
...
```
