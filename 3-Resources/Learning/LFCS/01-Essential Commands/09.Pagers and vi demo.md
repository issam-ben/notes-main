# Pagers
Are command line programs that allow to open multiple lines of text and navigate through them.

## less
- syntax:
```
less [file]
```

### Search text
- To search inside a text file with a pager we use '/'.
- To get to the next instance on a line press 'n' key.
- To get to the previous instance pres 'Shift+n' keys.
- less is case sensitive, to make it insensitive, pass '-i' option.
- To exit the pager press 'q' key.
- 
## more
It is similar to ==less==, but it doesn't have as many features as ==less==.
- To navigate through file in ==more==, use the *spacebar*.
- To exit the ==more== pager, press '*q*' key.

# vim
Vim is a command line editor, it stands for '*Vi improved*', so it is an improved derivative of '*vi*' text editor.
- Syntax:
```
vim [textfile]
```
vim is a mode sensitive text editor, means that it has many modes that work in different ways.

## vim modes
### Normal mode
It is the default mode that vim starts on. you can't type anything in this mode, only view the file. pressing 'Esc' key gets you back to the normal mode.

### Insert Mode
It is the editing mode in vim, to change to insert mode, press 'i' key while on vim, and start editing.

### Jump to Line
To jump to a line inside the text file use ':x', where 'x' is the number of line you want to go to.
### Copy/paste/cut a line of text
When you are in Command mode, go to to the line you want to copy, and type 'y' key twice, while in Command mode.
- to paste the line, go where you want to past it, and press 'p' key.
- to cut a line press 'd' key.

### Quit, save...
- To quite vim, type ':q'.
- To write changes type ':w'
- you can combine both commands.
- To force vim to do something, follow the command with '!'.
