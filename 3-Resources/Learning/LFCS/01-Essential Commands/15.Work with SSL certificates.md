# Overview
## SSL vs TLS
SSL (Secure Sockets Layer) is the predecessor of TLS, it is a deprecated IETF Standard specification of (1994, 1995, 1996).
TLS (Transport Layer Security), is the current standard nowadays, it was adapted by IETF in 1999, the latest version is TLS 1.3, defined in 2018. [-1-](https://en.wikipedia.org/wiki/Transport_Layer_Security) 

## What is SSL/TLS ?
Are encryption based internet security protocol, it was first defined by Netscape in 1995 (called SSL), later TLS, on the purpose of ensuring [[Privacy]], [[Authentication]], [[Integrity]].  
### Why still calling it SSL ?
SSL was used for a long time, so it stuck with various tools, and docs.
## What for ?
The purpose of using such protocols, is to encrypt data being transferred, and ensuring only the right parties has access to it.
# SSL Certificates ?
An SSL Certificate is a data file, hosted in a website's origin server, to make using SSL/TLS encryption possible.
## Creating SSL Certificates
Using Openssl in linux, we can create SSL certificates.
# [[Openssl]]
[[Openssl]] can deal with many cryptography related operations, not just certificates, and it provides many sub-commands.
==To get Help==:
`openssl help`
it will list many openssl sub commands, what is important to us in this case is the req and x509 sub commands.

`man openssl`: to show the man page of openssl.
man `openssl-req` or man `openssl req`: to show the req sub command man page.
## Create SSL/TLS Certificates with Openssl
### Certificate Signing Request (CSR)
A Message sent from an applicant, to a certificate authority of the [public key infrastructure](https://en.wikipedia.org/wiki/Public_key_infrastructure "Public key infrastructure")  
### Private Key
A cryptographic key, used to encrypt and decrypt data.
- Creating a Private key in OpenSSL
```
openssl req -newkey rsa:2048 -keyout key.pem -out req.pem
```
	- -newkey: to generate a new private key.
	-  rsa:2048: to encrypt the key with rsa-2048 algorithm.
	- -keyout: to specify the filename of the key, which in this case is, key.pem
	- -out: to specify the output filename of the CSR. 
### Self signing a Certificate
```
openssl -x509 -noenc -newkey rsa:4096 -days 365 -keyout myprivate.key -out mycertificate.crt
```
