## Devices
Linux treats everything as a file, devices are treated as file, as a type of Special Files, there are several kinds of device files, as follows:
- Block Devices: (such as HDDs, SSDs, USB Drives,...etc) it handles data in fixed-size blocks, used for filesystems and data storage, udev treats block devices as SCSI devices, it names them as sda, sdb, sdc, sde,...etc sd stands for SCSI Device, and a, b, c...etc as distinguishing between devices.
- Character Devices: facilitate real time input/output. they include devices like, Keyboards, Mice, Sound Cards, and Serial Ports. (e.g., /dev/tty , /dev/ttyUSB0 , /dev/ttyS0).
- Pseudo-Devices: Are software based simulation of hardware devices, most common examples of pseudo-devices are: 
	- /dev/null: discards any data written to it and returns end-of-life (EOF) condition when read from.
	- /dev/zero: provides stream of null bytes (zeros) when read from. useful for creating files filled with zeros or for initiating memory.
	- /dev/random and /dev/urandom: provide random numbers for applications, mostly used for cryptography.
	- /dev/loopX: allows a file to be used as a block device. commonly used for mounting filesystem images.
	- /dev/pts: pseudo terminal slave devices. used by terminal emulators and remote login programs like ssh, to provice terminal interface.
The /dev directory is the special directory that contains device files, representing devices, it is populated by the linux kernel's device manager ==*'udev'*==.
### Block Devices
Are storage devices that are used for permanent storage of data

#### Partitions 
Block devices can be divided into multiple partitions, Partitioning is like carving up a cake into smaller pieces, so that every piece has certain purpose. Partitioning computer storage can help in separating concerns, for ex, you make a partition for the OS, and another for user Home directory,...etc.
##### Partition Tables
There two famous PC Partitioning types:
- MBR (Master Boot Record): holds information on how the disc's sectors (blocks), are divided into partitions, each partition contains a filesystem. the addressable storage space that MBR can support is limited to 2 TiB.
- GPT (GUID Partition Table): The newest, part of UEFI standard, it doesn't have the limits that MBR has.
##### Listing Partitions

- lsblk
`lsblk`
