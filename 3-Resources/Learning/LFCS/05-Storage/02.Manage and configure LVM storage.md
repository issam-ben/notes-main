# 02.Manage and configure LVM storage

## What is LVM
Created by Redhat in 2001, LVM (short for: Logical Volume Manager), is a mechanism in Linux for managing Storage, it works by combining Disks or Partitions (Physical Volumes) into Volume Groups (VGs), making them look like a single disk, and then can partition them to Logical Volumes (LVs).
LVM can make it very easy to manage storage, it allows to resize the LVs on the fly, by adding new Disks to a VG, or removing one.

## LVM Components 
### Physical Volumes
These are real Disks or Partitions, LVM consider them as PVs, they are the basic component to create an LVM storage on Linux.
Physical Volumes commands start with the letters pv, 
#### Managing Physical Volumes

- Create Physical Volumes
To create a Physical Volume using a Disk or a partition, we use the command pvcreate followed by the path of the disk or partition as an argument:
```bash
sudo pvcreate /dev/vdd
```

- Listing available Physical Volumes
Use these Commands:
```bash
sudo pvscan
sudo pvs
sudo pvdisplay
```

- Change attributes of physical volume (pvchange)

- Checking Physical Volumes Metadata
Use the command ==pvck==:
```bash
sudo pvck /dev/vdd # Perform comprehensive check on a PV.
sudo pvck metadata /dev/vdd # Check metadata of PVs for inconsistencies.
```
For more info use this [tutorial](https://www.linuxoperatingsystem.net/pvck-command-in-linux/).
