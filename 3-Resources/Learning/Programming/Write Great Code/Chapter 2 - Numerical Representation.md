## What is a Number ?
To understand the concept of number we must distinguish between the number and the representation of it.
* Number is a tangible thing, it is real, it can be counted, like 100 pages of a book, 50 cows, 2 apples...etc
* The representation is just a way of describing the actual number (called *glyphs*), and the symbols 100 is not the real one hundred, it's just a representation (digit), and it's not the only one, the table below shows some of known representation of the number 100:

| Value                    | Numering System            |
| ------------------------ | -------------------------- |
| 100                      | Decimal representation     |
| C                        | Roman Numerals             |
| $$\mathrm{64}_{16}$$     | Base-16 (Hexadecimal)      |
| $$\mathrm{1100100}_{2}$$ | Base-2 (Binary)            |
| $$\mathrm{144}_{8}$$     | Base-8 (Octal)             |
| one hundred              | Natural Language (English) |

> [!NOTE]
> Differentiating between a number (value), and the representation of it (digits), can help us in computers in a way that we might face numbers when dealing with computer programs, though 100 might represent the actual 100 value, or it is in Base64, which means it is not the value 100.

## Numbering Systems
A numbering system is a mechanism to represent numeric values.
Numbering systems are considered based on their base (radix)@Radix2024, meaning the digits the system have, if it has one digit it is considered unary system, if two then binary, if three then ternary system.
### Unary Numeral System
A Unary system is a system that represents numbers using one symbol (digit), repeated based on the number's value. To represent a number N, a symbol representing1 is repeated N times@UnaryNumeralSystem2024. the most known technique of this system is ==Tally-slash== or ==Tally Mark== or ==Hash Marks==
