### Risks against 
1- [[Denial of service attacks]]: (DoS), occurs when a malicious party bombards a system with an overwhelming network traffic. 
	-Protection: Firewalls that blocks illegitimate requests can be a good protection against such attacks.
2- Power Outage: can occur for many reasons, and can be local or regional, like natural disasters, increase demand..etc
	-Protection: A buck up plan like power generators and batteries to supply power when there is an outage in the main grid.
3- Hardware Failures: it can happen for many reasons, like hard drives failure, network, ...etc
	-Protection: Ensure building systems with [[redundancy]] in mind, if one fails another is ready to take responsibility.
4- Service outage: It is when the service itself becomes unavailable, this can be due to programming errors, configuration mistakes, ...etc
	-Protection: Ensuring that systems are resilient to such errors, like using cluster computing...etc.
